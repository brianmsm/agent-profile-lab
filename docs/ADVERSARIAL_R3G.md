# Agent Profile Lab R3g — local trust-boundary correction

**Status:** unsigned local review candidate. No signing, push, merge, Pages
deployment, active agents or paid inference is authorized in this phase.

## Changed controls

**Cryptographic Git chain:** the shared Git reader now checks raw commit
object OIDs and parent histories, recursively checks tree OIDs, and binds
ls-tree path/mode inventories to authenticated tree bytes. Selected leaf
blob bytes are also cryptographically verified. Synthetic forged tree
and commit OID negatives must be rejected by the maintenance planner.

**Publisher content:** the Python DLP guard now uses typed JSON, parsed
SVG/XML (including entity and CDATA handling) and lexically grouped
JS/JSX data containers instead of endlessly adding numeric-expression
regular expressions. Unknown external publisher labels and metric fields
are held for human review regardless of literal/expression syntax or
property order. Only expressly typed reference-count aggregations WITHOUT
score columns, local synthetic fixtures and approved BFCL observations
remain eligible. This is not a complete JS semantic proof or rights license.

**Private staging:** the future local release protocol must prepare a
separate exact-SHA Git clone inside private ignored storage, copy offline
frontend dependencies, hash/verify sources and Pages, and mark the source
read-only. Prepublish refuses a mutable checkout and verifies that the
source and both Pages directories come from the same frozen stage.
The operating publisher must ensure exclusive writers through validation,
signature and the first public push. A same-UID malicious writer or
compromised host is outside this local model; chmod is not a mandatory
kernel-enforced write prohibition.

new signature or publication.
