# Development provenance and preserved private history

This is the publication history disclosure for Agent Profile Lab.

**Origin:** the full research working tree was developed in **39 local Git commits**
from 2026-10-09 through 2026-10-13. Its original Git object history is
**intentionally excluded** from this new public repository: earlier revisions
contain external benchmark captures and data, including Artificial Analysis
measurements that are not authorized for bulk redistribution in this package.

The original history is **not lost**: it is preserved intact in the author's
unpublished local research repository and in a verified offline Git bundle.
A separate private agent-profile-lab-internal repository is planned, but
this public release does not create it.

## New public Git history

The new public repository contains several **new, legitimate commits**
representing the staged assembly of the reviewed rights-scoped public code,
original profile reference data, frontend, evidence links, CI and documentation.
Those commits are **not** presented as the original historical commits or
as a replay of original private repository contents.

This approach preserves a meaningful, inspectable public change history while
avoiding accidental redistribution from deleted files, historical screenshots
or research datasets. Published profile decisions remain identical to their
private-origin counterparts (SHA-256 parity is checked by the release verifier).
The owner can retain the entire historical research development tree in the
future private repository without force-pushing or rewriting its commits.

**No prior research Git history, private refs or raw capture blobs are
contained within the packaged source distribution.**
